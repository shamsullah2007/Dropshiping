🔍 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════

ISSUE: Videos not showing
FIX: 
  1. Check wp_postmeta for _product_video_ids
  2. Verify video files are in wp-uploads
  3. Check browser console for errors

ISSUE: Gallery thumbnails not clickable
FIX:
  1. Clear browser cache (Ctrl+Shift+R)
  2. Check browser console (F12)
  3. Verify cj-single-product.js is loaded

ISSUE: Images not loading
FIX:
  1. Check WordPress media permissions
  2. Verify file permissions on wp-uploads folder
  3. Check database for attachment URLs

ISSUE: Layout looks broken
FIX:
  1. Clear all caches (browser + server)
  2. Verify CSS file exists: assets/css/cj-single-product.css
  3. Check browser DevTools → Network tab for 404 errors

ISSUE: Default WooCommerce template still showing
FIX:
  1. Verify: woocommerce/single-product.php exists
  2. Check: WordPress is not using cached template
  3. Flush: WordPress rewrite rules (Settings → Permalinks → Save)
