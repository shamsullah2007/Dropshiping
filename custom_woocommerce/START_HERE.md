📋 VIDEO UPLOAD GUIDE
═════════════════════════════════════════════════════════════════════════

To add videos to a product:

1. Admin Panel → Product Manager → Add Single Item

2. Scroll to "Product Videos (Optional)" section

3. Click file input and select video files:
   • Supported formats: MP4, WebM, OGG, MOV, AVI
   • Can select multiple files at once
   • Previews show in real-time

4. Video preview will display in form

5. Submit form → Videos saved to WordPress media

6. Visit product page → Videos appear in gallery!

Videos display with:
  ✓ Play icon overlay on thumbnail
  ✓ Muted playback
  ✓ Auto-loop
  ✓ Full video player controls

🔧 QUICK CUSTOMIZATION

Change Gallery Width:
  Edit: /assets/css/cj-single-product.css
  Line 9: grid-template-columns: 420px 1fr;

Change Red Color:
  Edit: /assets/css/cj-single-product.css
  Search: #ff4d4f
  Replace with your color (e.g., #ff6b6b or #e74c3c)

Change Background:
  Edit: /assets/css/cj-single-product.css
  Search: #f5f5f5
  Replace with your color (e.g., #ffffff or #f0f0f0)

Change Animation Speed:
  Edit: Both CSS and JS files
  Search: 0.3s
  Replace with: 0.5s (slower) or 0.15s (faster)
