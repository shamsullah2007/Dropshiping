───────────────────────────────────────────────────────────────
❓ TROUBLESHOOTING:
───────────────────────────────────────────────────────────────

Videos not showing?
  → Check in wp_postmeta table for _product_video_ids
  → Verify videos uploaded via Product Manager form

Thumbnails not working?
  → Clear browser cache (Ctrl+Shift+R)
  → Check browser console for JS errors (F12)

Layout broken?
  → Verify cj-single-product.css file exists
  → Clear server cache
  → Flush rewrite rules (Settings → Permalinks → Save)

Default template still showing?
  → Verify woocommerce/single-product.php exists
  → Check theme is active
  → Clear all caches

💡 CUSTOMIZATION:
───────────────────────────────────────────────────────────────

Change Colors:
  Edit: assets/css/cj-single-product.css
  Search: #ff4d4f (red), #f5f5f5 (gray), #e5e5e5 (borders)

Change Layout Width:
  Edit: line 9 in cj-single-product.css
  Default: grid-template-columns: 420px 1fr

Change Animation Speed:
  Edit: 0.3s ease in CSS
  Change to: 0.5s (slower) or 0.15s (faster)
